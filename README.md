# Финансовый шарик — интерактивный прототип

Концепция: клиент задаёт вопрос → встряхивает шар → шар наклоняется и в окошке
всплывает треугольник с позитивным ответом.

**Демо:** ссылка в описании репозитория (GitHub Pages).

## Как устроено

- 3D-модель шара собрана в Blender, экспортирована в `assets/ball.glb`
- Сцена, свет и анимация — three.js (библиотека лежит локально, без CDN)
- Анимация игровая, не видеоролик: встряска, наклон и всплытие считаются в рантайме

## Текст ответа — переменная

Ответ рисуется на треугольнике в момент показа. За выбор отвечает одна функция
в `index.html`:

```js
async function pickAnswer(question) { ... }
```

Сейчас это случайный выбор из пяти позитивных ответов ТЗ. Для боевой версии
тело функции заменяется вызовом API — остальной код не меняется.

## Локальный запуск

```bash
python3 -m http.server 8123
```
Затем открыть http://127.0.0.1:8123 (нужен http-сервер: GLB и шрифты не грузятся с `file://`).
